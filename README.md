# Snapdeal ML Project

This project contains an analysis of Snapdeal data, including cleaned data,
the analysis notebook, and a findings presentation.

## Contents

- `SnapDeal.csv` - source dataset
- `SnapDeal_cleaned.csv` - cleaned dataset
- `Snapdeal_Analysis.ipynb` - analysis notebook
- `Snapdeal_Findings_Presentation.pptx` - presentation of findings
